貼り付け枠の色くらべ

同じ中身を4パターンで並べました。上の「黒い見出し帯」との境目の見え方を比べてください。

B薄いグレー地に黒文字 ── おすすめ

見出しの黒帯と明暗が逆になるので、境目が確実に立ちます。新聞の囲み記事らしさも一番出ます。

3-1安全装置をつくらせる

貼り付ける 1/2
Claude Code のフック（＝操作の直前に自動で走る見張り番）を設定してください。
私のパソコンは Windows です。Git for Windows は入れてあります。

【つくってほしい仕組み】
A. 本体セッションのモデルが opus のとき、Edit と Write をブロックする。
   ただし次は例外として許可する：
   - .md / .txt などの文書ファイル
   - .claude フォルダの中のファイル
終わったら、バックアップの置き場所をメモしておいてください
